# Examples

Valid and invalid schema examples for the parent wrapper live here.

Parent-native orchestration coverage now includes peer mesh, peer message,
peer lifecycle, observability event, policy decision, peer mesh runtime, agent
role, hook manifest, bounded capability matrix, observability ingest, library
distribution, and benchmark emission examples, including explicit role-class,
command-guard, governed-operation, typed-reference, and regression-surface
cases. Research governance now also carries a valid and invalid
`research-packet-manifest` example so the compiled harvest lane is exercised as
governed parent data. Ratchet report and iteration examples now also carry
structured runtime-truth, blocker, freshness, command-evidence, and
score-saturation cases. The inbox/front-door slice adds JSON examples for the
packet contract family plus Markdown packet examples that show the required
front matter, Markdown body, and `---bottom-matter---` envelope used at the
human-facing front door.
