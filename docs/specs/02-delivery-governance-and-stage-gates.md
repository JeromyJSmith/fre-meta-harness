# Delivery Governance and Stage Gates

## Stage-gate pipeline
- Intake gate
- Contract conformance gate
- Runtime truth and blocker precision gate
- Observability coverage gate
- Reproducibility evidence gate
- Readiness alignment gate

## Policies
- Rollback on any failed gate after tentative integration
- Preserve rejected probes in ledger and reports
- Never convert blocked lanes to green without exact prerequisites satisfied

## Promotion criteria
- Validator pass
- Evidence artifact presence and freshness
- Explicit runtime truth level
- No governance/runtime role collapse
