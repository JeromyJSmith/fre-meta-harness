# Test and Validation Strategy

## Validation strategy
Map validator checks to promotion gates:
- Schema/contract conformance -> schema_and_example_validation
- Runtime truth and blocker precision -> tool_health_truth_boundaries
- Observability coverage -> observability ingest + runtime truth checks
- Reproducibility evidence -> iteration ledger + score history alignment
- Readiness evidence alignment -> promotion/readiness contract checks

## Test levels
- Contract/schema tests
- Topology and role-separation tests
- Runtime lane activation evidence tests
- Regression and freshness tests
