# runs

Append-only run history.

<aside>
📎

**Purpose**: Append-only evidence ledger of what happened, what changed, and why we kept/reverted it.

**Inputs**: Plan used, validation outputs, scorecards, reports, action logs.

**Outputs**: Run files (`runs/0001.md`, …) that make the harness auditable and replayable.

**Validation tie-in**: Replay tests (reconstruct), Observability checks (evidence exists), Publish decision (ship only with evidence).

**Failure modes**: No run log → no reproducibility; missing links → unverifiable improvement claims.

**Update / upstream path**: Run-log schema changes must update schemas/examples and be backwards compatible.

</aside>

```yaml
page_contract:
  purpose: "Append-only run ledger for auditability + replay."
  inputs: ["plans", "validation outputs", "reports", "action logs"]
  outputs: ["runs/####.md files"]
  validation_tie_in:
    gates: ["Replay tests", "Observability checks", "Publish decision"]
    checks:
      - "Each run links plan/scorecard/report/action-log pointer"
  failure_modes:
    - "Unreplayable work"
    - "No evidence for decisions"
  upstream:
    update_artifact: "Run-log contract update artifact"
    proposal_path: "Update schema+example + validate"
```
