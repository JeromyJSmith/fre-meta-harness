# memory.md

## Memory (stable)

<aside>
📎

**Purpose**: Stores stable invariants + decisions so the ecosystem doesn’t re-litigate fundamentals and silently drift.

**Inputs**: Prior run logs; accepted decisions; invariants discovered via failures.

**Outputs**: A stable constraint set that validators and operators rely on.

**Validation tie-in**: Static checks (policy/invariants), Drift detection (decision violations), Replay tests (consistency).

**Failure modes**: Without invariants, each run becomes a new worldview; portability breaks via hidden assumptions.

**Update / upstream path**: Any new invariant/decision must cite evidence (run log) and be upstreamed into templates/rules.

</aside>

```yaml
page_contract:
  purpose: "Stable invariants + decisions for reproducible operation."
  inputs: ["Run logs", "Validation failures", "Accepted decisions"]
  outputs: ["Invariants", "Decisions", "Rolling learnings"]
  validation_tie_in:
    gates: ["Static checks", "Drift detection", "Replay tests"]
    checks:
      - "No invariant violations in current run outputs"
  failure_modes:
    - "Repeated regressions"
    - "Hidden assumptions break portability"
  upstream:
    update_artifact: "Memory/invariants update artifact"
    proposal_path: "Record evidence + patch templates/rules + validate"
```
