# schemas

Schema contracts live here.

<aside>
📎

**Purpose**: Canonical schema directory for machine-validated contracts for every artifact in the portable harness.

**Inputs**: Artifact Registry + Output Styles; existing artifact examples in `examples/`.

**Outputs**: `*.schema.json` files used by validators and the spec compiler.

**Validation tie-in**: Contract validation (schemas present), Static checks (schemas parse), Drift detection (schema version changes).

**Failure modes**: Missing schema makes artifacts unlintable; schema drift without versioning breaks replayability.

**Update / upstream path**: Any schema change requires a matching example update + run log note + drift report.

</aside>

```yaml
page_contract:
  purpose: "Schema directory for portable harness artifacts."
  inputs: ["Artifact definitions", "examples/"]
  outputs: ["JSON Schemas for validation"]
  validation_tie_in:
    gates: ["Contract validation", "Static checks", "Drift detection"]
    checks:
      - "Every artifact type has a schema + example"
  failure_modes:
    - "Artifacts without schemas"
    - "Schemas without examples"
  upstream:
    update_artifact: "Schema-change update artifact"
    proposal_path: "Update schema+example + rerun validate + record drift"
```
