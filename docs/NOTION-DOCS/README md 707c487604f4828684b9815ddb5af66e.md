# README.md

## runs/

Append-only run history.

<aside>
📎

**Purpose**: Defines what every run must contain so the system is replayable and decisions are auditable.

**Inputs**: Plan used; validation outputs; compiler outputs; scorecards/reports; action log pointers.

**Outputs**: A run file per run with standardized links and decision record.

**Validation tie-in**: Replay tests + Observability checks + Publish decision.

**Failure modes**: Runs without links cannot be reconstructed; decisions without evidence cause drift.

**Update / upstream path**: Run format changes must update schemas/examples and preserve backward compatibility.

</aside>

```yaml
page_contract:
  purpose: "Run-log requirements for replayability + auditability."
  inputs: ["plan", "validation outputs", "reports/scorecards", "action logs"]
  outputs: ["runs/####.md convention + required links"]
  validation_tie_in:
    gates: ["Replay tests", "Observability checks", "Publish decision"]
    checks:
      - "Each run links plan/scorecard/report/action-log pointer"
  failure_modes:
    - "Unreplayable work"
    - "Unverifiable keep/revert decisions"
  upstream:
    update_artifact: "Run-log-contract update artifact"
    proposal_path: "Patch docs+schemas/examples + rerun validate"
```

### Minimum v1 convention

- One file per run: `runs/0001.md`, `runs/0002.md`, ...
- Each run must link to:
    - plan file used
    - scorecard
    - report
    - action log pointer
