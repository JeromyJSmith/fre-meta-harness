# README.md

## schemas/

Schema contracts for harness artifacts.

<aside>
📎

**Purpose**: Human-readable index for the `schemas/` directory and its minimum required contracts.

**Inputs**: Artifact Registry; Output Styles; current set of artifacts the harness produces.

**Outputs**: A checklist of required schemas and the rule that each schema must have a matching example.

**Validation tie-in**: Contract validation (required schemas exist), Static checks (schemas parse), Drift detection (schema set changes).

**Failure modes**: Missing schema breaks machine validation; schemas without examples break trust.

**Update / upstream path**: When adding a new artifact type, add its schema here + add an example + record in run log.

</aside>

```yaml
page_contract:
  purpose: "Index and checklist for required schemas."
  inputs: ["Artifact Registry", "Output Styles", "Artifact set"]
  outputs: ["Required schema checklist", "Schema↔example pairing rule"]
  validation_tie_in:
    gates: ["Contract validation", "Static checks", "Drift detection"]
    checks:
      - "All required schemas exist and parse"
      - "Each schema has a matching example"
  failure_modes:
    - "Unvalidated artifacts"
    - "Schema/example mismatch"
  upstream:
    update_artifact: "Schema-index update artifact"
    proposal_path: "Update README + add schema+example + rerun validate"
```
