# README.md

## reports/

<aside>
📎

**Purpose**: Defines the report surface (human-readable) that makes validation and decisions auditable and sendable.

**Inputs**: Compiler outputs; run logs; scorecards; action log pointers.

**Outputs**: Report artifacts (HTML/MD/JSON) referenced by run logs and publish decisions.

**Validation tie-in**: Observability checks (evidence exists), Publish decision (ship only with evidence).

**Failure modes**: No report → no audit trail; unlinked reports → unverifiable claims.

**Update / upstream path**: Report shape changes must be reflected in schemas/examples and revalidated.

</aside>

```yaml
page_contract:
  purpose: "Report conventions for portable harness auditability."
  inputs: ["compiler/*", "runs/*", "scorecards", "action logs"]
  outputs: ["Portable reports referenced by runs"]
  validation_tie_in:
    gates: ["Observability checks", "Publish decision"]
    checks:
      - "Each run links to required reports/scorecards"
  failure_modes:
    - "No evidence for decisions"
    - "Unverifiable validation outcomes"
  upstream:
    update_artifact: "Report-contract update artifact"
    proposal_path: "Update docs+schemas/examples + rerun validate"
```

Templates + generated run reports.
