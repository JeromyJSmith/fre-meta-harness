# artifact.schema.json

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "artifact.schema.json",
  "title": "Artifact Record Schema",
  "type": "object",
  "additionalProperties": false,
  "required": [
    "artifactId",
    "type",
    "path",
    "ownerAgent",
    "schema",
    "example"
  ],
  "properties": {
    "artifactId": { "type": "string", "pattern": "^[a-z0-9-]+$" },
    "type": {
      "type": "string",
      "enum": [
        "doc",
        "schema",
        "report",
        "config",
        "log",
        "plan",
        "agent",
        "skill",
        "rule",
        "style"
      ]
    },
    "path": { "type": "string" },
    "ownerAgent": { "type": "string", "pattern": "^[a-z0-9-]+$" },
    "schema": { "type": "string" },
    "example": { "type": "string" },
    "validator": { "type": "string" },
    "provenance": {
      "type": "object",
      "additionalProperties": true,
      "properties": {
        "sources": { "type": "array", "items": { "type": "string" } },
        "pins": { "type": "array", "items": { "type": "string" } }
      }
    }
  }
}
```

<aside>
📎

**Purpose**: Machine contract for each record in the Artifact Registry (what exists, where it lives, who owns it, and how it’s validated).

**Inputs**: Registry expectations (artifact types); schema+example pairing rules.

**Outputs**: A schema validators can use to enforce that every artifact is declared and testable.

**Validation tie-in**: Contract validation (registry completeness), Drift detection (new/changed artifacts), Publish decision (ship only with declared artifacts).

**Failure modes**: Undeclared artifacts become “dead grass” (ignored dependencies) and the ecosystem breaks silently.

**Update / upstream path**: New artifact types require schema updates + registry updates + examples + compiler rule updates.

</aside>
