# Agents

Place META-HARNESS agent role contracts in this directory. Each contract should be named `role-name.contract.json` and validate against `schemas/agent-role-contract.schema.json`.

Agent contracts should define:

- Role purpose and domain.
- Allowed artifact types.
- Inputs and outputs.
- Read, write, execute, and network permissions.
- Operating rules.
- Validation responsibilities.
- Handoff and escalation behavior.
