# crm.explainer.md

## CRM CSV explainer (human readable)

This CSV is designed to be Salesforce-adjacent while staying portable.

### Required columns

- `id` (primary key)
- `record_type` (Lead|Contact|Account|Opportunity)

### Guidance

- Use empty strings for unknown values.
- Use ISO-8601 for `created_at`/`updated_at`.
- Don’t put secrets in `notes`.
