# examples

Canonical examples for each schema/artifact.

<aside>
📎

**Purpose**: Canonical example directory that proves schemas are usable and artifacts are reproducible.

**Inputs**: `schemas/*` contracts; output-style rules; current golden path expectations.

**Outputs**: Example files (md/jsonl/csv/etc.) that validators can run against schemas.

**Validation tie-in**: Golden tests (expected snapshots), Contract validation (schema↔example pairing), Replay tests (deterministic examples).

**Failure modes**: Schemas without examples become theory; examples without schemas become untrusted.

**Update / upstream path**: Every new schema requires a matching example; changes must be recorded in a run log.

</aside>

```yaml
page_contract:
  purpose: "Canonical examples that validate against schemas."
  inputs: ["schemas/*", "output styles"]
  outputs: ["Example artifacts used by validators"]
  validation_tie_in:
    gates: ["Golden tests", "Contract validation", "Replay tests"]
    checks:
      - "Example set covers required schemas"
  failure_modes:
    - "Schemas without examples"
    - "Examples drift from schemas"
  upstream:
    update_artifact: "Example-set update artifact"
    proposal_path: "Update example + rerun schema validation + record"
```
