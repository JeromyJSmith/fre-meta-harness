# Governance

This repository uses explicit lifecycle promotion instead of implicit document authority.

## Roles

- Repository steward: owns directory conventions, schemas, and canonical registry hygiene.
- Research owner: owns evidence quality and RDD traceability.
- Spec owner: owns architectural commitments and implementation alignment.
- Validation owner: owns test evidence, acceptance criteria, and gate outcomes.
- Agent owner: owns role contracts, permissions, and handoff boundaries.

## Review rules

- No document becomes `Canonical` without at least one reviewer listed in manifest front matter.
- No implementation output is accepted without a validation record.
- No agent may update canonical artifacts unless its role contract grants write permission to canonical paths.
- Superseded documents must point to the replacement artifact.

## Canonical registry

Use `docs/canonical-registry.md` to list the current canonical documents and their supersession lineage.
