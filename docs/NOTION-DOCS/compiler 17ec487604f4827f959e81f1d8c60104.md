# compiler

Spec compiler artifacts (markdown-first enforcement).

<aside>
📎

**Purpose**: Enforcement surface that turns docs/schemas into a “what’s missing / what broke” compliance output.

**Inputs**: `docs/harness/*`, `schemas/*`, `examples/*`, Output Styles, Artifact Registry.

**Outputs**: `compliance.md` and `missing.md` (and any future compiler outputs).

**Validation tie-in**: Static checks + Drift detection (compiler flags gaps), Publish decision (cannot ship if missing list non-empty).

**Failure modes**: Without compiler outputs, completeness becomes subjective; [missing.md](http://missing.md) becomes invisible debt.

**Update / upstream path**: Any new artifact type must update compiler rules + schemas/examples.

</aside>

```yaml
page_contract:
  purpose: "Spec compiler outputs and enforcement artifacts."
  inputs: ["docs/harness/*", "schemas/*", "examples/*"]
  outputs: ["compiler/compliance.md", "compiler/missing.md"]
  validation_tie_in:
    gates: ["Static checks", "Drift detection", "Publish decision"]
    checks:
      - "Compiler outputs exist and are linked from run log"
  failure_modes:
    - "Silent missing artifacts"
    - "Unenforced standards"
  upstream:
    update_artifact: "Compiler update artifact"
    proposal_path: "Patch compiler rules + rerun validate"
```
