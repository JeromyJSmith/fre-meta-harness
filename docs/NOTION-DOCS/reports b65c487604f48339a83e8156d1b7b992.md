# reports

Report templates + generated reports.

<aside>
📎

**Purpose**: Report surface for human-readable outputs (compliance summaries, drift reports, scorecards).

**Inputs**: Compiler outputs, run logs, validation results.

**Outputs**: Portable report files referenced by run logs and publish decisions.

**Validation tie-in**: Observability checks (reports exist + linked), Publish decision (shipability evidence).

**Failure modes**: No report → no audit trail; missing links → unverifiable claims.

**Update / upstream path**: Report format changes require schema + example updates and a rerun to green.

</aside>

```yaml
page_contract:
  purpose: "Report templates + generated reports for auditability."
  inputs: ["compiler outputs", "runs/*", "validation results"]
  outputs: ["Portable reports (human + machine references)"]
  validation_tie_in:
    gates: ["Observability checks", "Publish decision"]
    checks:
      - "Run log links to report(s)"
  failure_modes:
    - "No audit trail"
    - "Unlinked validation evidence"
  upstream:
    update_artifact: "Report-format update artifact"
    proposal_path: "Update schemas/examples + rerun validate"
```
