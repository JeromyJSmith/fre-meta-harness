# Examples

The example artifacts demonstrate a minimal Vectorworks-to-iTwin living-document chain:

1. `rdd/vectorworks-itwin-spatial-pipeline.md` defines requirements and acceptance criteria.
2. `examples/research/vectorworks-export-research.md` captures export-path research.
3. `examples/specs/vectorworks-itwin-mapping.md` defines a canonical semantic mapping example.
4. `examples/agents/spatial-mapping-agent.contract.json` defines an agent role contract.
5. `examples/validations/vectorworks-itwin-mapping-validation.md` records validation evidence and promotion recommendation.

Use these examples as patterns, not as project-specific authority.
