# golden-path.md

## Golden Path (fresh export → green)

<aside>
📎

**Purpose**: The canonical “fresh start” procedure that proves the portable package can reach **green** deterministically.

**Inputs**: Exported Portable Harness Package; required entrypoints + schemas.

**Outputs**: A validated run (green) + compiler outputs + run log.

**Validation tie-in**: This *is* the validation choreography: contract/config/static → compiler outputs → run log evidence.

**Failure modes**: If steps are incomplete or non-commandable, reproducibility fails.

**Update / upstream path**: Any change to the golden path requires an Update Artifact + fresh-export revalidation.

</aside>

```yaml
page_contract:
  purpose: "Fresh export -> green procedure."
  inputs: ["Portable export output", "schemas/", "compiler/", "runs/"]
  outputs: ["Green validation run", "compiler/compliance.md", "compiler/missing.md", "runs/0001.md"]
  validation_tie_in:
    gates: ["Golden tests", "Replay tests"]
    checks:
      - "All required paths exist"
      - "Run log created and complete"
  failure_modes:
    - "Missing required files"
    - "Non-deterministic steps"
  upstream:
    update_artifact: "Golden-path update artifact"
    proposal_path: "Patch + rerun from fresh export"
```

1. Export `Portable Harness Package (Export Root)` as **Markdown & CSV** with **Create folders for subpages** enabled.
2. In the exported folder, confirm these paths exist:
    - `CLAUDE.md`
    - `docs/harness/goal.md`
    - `docs/harness/memory.md`
    - `docs/harness/golden-path.md`
    - `docs/harness/sources.md`
    - `.claude/settings.json`
    - `schemas/README.md`
3. Add schemas under `schemas/` and matching examples under `examples/` (required for full validation).
4. Run the “spec compiler” checklist (see `compiler/README.md`) and produce:
    - `compiler/compliance.md`
    - `compiler/missing.md`
5. Record the run as `runs/0001.md`.

### Done means

- All required artifacts exist.
- A run log exists and links to plan + outputs.

## Goal: Local model readiness

Design target: make the portable harness so contract-driven and opinionated that most golden-path steps can be executed and validated by small local models (single file agents with strict IO), with cloud models used only as escalation.

Reference note: Local Models Goal — Single File Agents + Strict Contracts

### Common failures

- Missing folder creation: re-export with “Create folders for subpages” enabled.
- Broken filenames: ensure `CLAUDE.md` casing is correct.
